# SkyAutoMusic Sheets

SkyAutoMusic 的独立曲库发布仓库。曲库以 GitHub Release ZIP 形式发布，供 [sky.xxlab.dev](https://sky.xxlab.dev) 和应用内更新器下载。

## 当前版本

- 版本：`2026.07.27`
- 曲谱：17,700 首 JSON
- 下载：[GitHub Release](https://github.com/Aknices-QWQ/SkyAutoMusic-Sheets/releases/tag/2026.07.27)
- SHA-256：`b7ab7e4e34a1e6e9000002f88564ad596be3ea49c29968f0984495c96def31f3`

曲库 ZIP 中的 JSON 文件位于压缩包根目录，便于客户端安全、增量地覆盖安装。

安装完整曲库后，客户端只下载版本之间的增量 ZIP；新增和修改文件位于增量包内，删除文件记录在更新清单的 `remove` 数组中。
